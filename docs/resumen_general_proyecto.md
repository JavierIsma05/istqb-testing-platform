# Resumen general del proyecto

Este proyecto es una plataforma web desarrollada en Django para gestionar el ciclo de vida de pruebas de software con enfoque ISTQB/STLC. Su objetivo principal es apoyar proyectos academicos o de titulacion mediante el registro ordenado de proyectos, requisitos, planes de prueba, casos de prueba, ejecuciones, defectos, incidentes, trazabilidad, reportes, auditoria y seguimiento por fases.

La plataforma si cumple con las fases principales del proceso de pruebas: analisis de requisitos, planificacion, diseno de pruebas, preparacion, ejecucion, gestion de defectos y cierre mediante informes. Tambien incorpora criterios de avance por fase, lo que permite validar si el trabajo progresa con evidencias reales y no solo con registros manuales.

En trazabilidad, el sistema relaciona proyecto, requisitos, casos de prueba, ejecuciones y defectos. Esto permite identificar que requisitos estan cubiertos, que casos los validan, cuales fueron ejecutados y que defectos surgieron. La matriz de trazabilidad y los reportes consolidan esta informacion.

El proyecto tambien cuenta con metricas implementadas. Entre las mas importantes estan cobertura de requisitos, avance de ejecucion, tasa de aprobacion, densidad de defectos, defectos por estado/severidad, evidencia registrada, revision docente, riesgos altos, progreso de fases, criterios de salida e indice global de trazabilidad.

En resumen, es una plataforma alineada con ISTQB, con trazabilidad funcional y metricas utiles para evaluar calidad y avance.
